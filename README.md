# Offbeat Creations Co. — storefront starter

Static responsive website prototype for offbeatcreationsco.com.

## Preview
Open `index.html` in a browser. For local development, use a static server such as `python -m http.server 8000`.

## Important: not yet live for orders
The custom-order form currently **only prepares a copyable request in the visitor's browser**. It does not email, save, or transmit requests. This is intentional: do not collect customer personal information until secure backend storage, authentication, spam protection, privacy policy, and notifications are configured. The gallery is clearly labeled as placeholders. No checkout or admin dashboard has been connected.
